# 📚 Book Browser Web Application

## 📌 Description

A dynamic front-end web application that allows users to browse, search, and filter a collection of books. Book data is rendered entirely using JavaScript and DOM manipulation, with no hard-coded book cards in the HTML. Users can click on books to view detailed information in a dedicated details section.

---

## 🚀 Features

* Dynamically renders a list of books using JavaScript
* Search books by title in real time
* Filter books by category/genre
* Clickable book cards to view detailed information
* Dedicated book details section that updates dynamically
* Responsive grid layout for book display
* Clean card-based UI design for better readability
* Dark mode toggle for improved user experience
* Smooth scrolling to details section on selection
* Fully interactive UI using event listeners (click, input, change)

---

## 🎯 User Experience

- As a user, I want to search for books by title

## ⚙️ Installation & Setup

1. Clone the repository:

git clone https://github.com/amandagm77/PracticeProject_BookBrowserWebApp

2. Open the project folder in VS Code.

3. Ensure image paths inside script.js match your /images folder.

4. Run the project using the Live Server extension.

---

## ▶️ Usage

1. Open the application in the browser.

2. Browse the list of available books.

3. Use the search bar to find books by title.

4. Use the category dropdown to filter results.

5. Click on a book card to view full details.

6. Toggle dark mode for an alternate theme experience.
